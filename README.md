# js-projects

15 проектов на чистом JavaScript: игры, конвертеры, приложения. Без фреймворков.

## Структура

### Игры (`/games`)
- **303.html** — Камень-ножницы-бумага
- **307.html** — Виселица (IndexedDB, canvas, 3 категории слов)
- **309.html** — Морской бой на время (генерация расстановки, localStorage)
- **401.html** — 5 в ряд (сетка 15×15, сохранение партии)
- **501.html** — Найди пару (таймер, превью карт)
- **503.html** — Змейка (canvas, игровой цикл, коллизии)

### Конвертеры (`/converters`)
- **304.html** — Конвертер длины
- **402.html** — Конвертер величин (длина, масса, площадь, объём)
- **502.html** — Конвертер валют

### Приложения (`/apps`)
- **306_403.html** — Кулинарная книга (101 рецепт, поиск по ингредиентам)
- **308_404.html** — Список дел (Map-хранилище, работа с датами)
- **310_405.html** — Фактотека (4 категории фактов)
- **311_406.html** — Фактотека + фильтры (сортировка, 5 категорий фильтров)

### Медиа (`/media`)
- **302.html** — Видеоплеер
- **305.html** — Генератор цитат

## Технологии

- HTML5, CSS3 (flex, grid, градиенты, анимации)
- JavaScript (DOM, события, canvas, localStorage, IndexedDB)
- Без фреймворков и библиотек

## Как запустить

Открой любой `.html` файл в браузере. Или через **GitHub Pages**.
