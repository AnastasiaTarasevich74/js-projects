# js-projects

**Живое демо:** [anastasiatarasevich74.github.io/js-projects](https://anastasiatarasevich74.github.io/js-projects/)

15 проектов на чистом JavaScript: игры, конвертеры, приложения. Без фреймворков и библиотек.

## Игры (`/games`)

- [Камень-ножницы-бумага](games/303.html) — игра против компьютера
- [Виселица](games/307.html) — IndexedDB, canvas, 3 категории слов
- [Морской бой](games/309.html) — таймер, localStorage, сетка 10×10
- [5 в ряд](games/401.html) — сетка 15×15, сохранение партии
- [Найди пару](games/501.html) — таймер, memory game
- [Змейка](games/503.html) — canvas, игровой цикл, коллизии

## Конвертеры (`/converters`)

- [Конвертер длины](converters/304.html) — метры, футы, дюймы, км, мили

## Приложения (`/apps`)

- HTML5, CSS3 (flex, grid, градиенты, анимации)
- JavaScript (DOM, события, canvas, localStorage, IndexedDB)
- Без фреймворков и библиотек

## Как запустить

Открыть любой `.html` в браузере или зайти на [живое демо](https://anastasiatarasevich74.github.io/js-projects/).
